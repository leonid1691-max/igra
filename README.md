# Между нами 1330 км

Романтическая мини-игра для Даши и Лёни. Приложение можно бесплатно опубликовать через GitHub Pages.

## Как загрузить сайт на GitHub

1. Войдите на [github.com](https://github.com/) или создайте аккаунт.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Назовите репозиторий, например `between-us-1330`. Выберите **Public** и нажмите **Create repository**.
4. На странице нового репозитория нажмите **Add file** → **Upload files**.
5. Откройте папку `between-us` на компьютере и перетащите в окно GitHub оба файла: `index.html` и `README.md`. Перетаскивайте сами файлы, чтобы `index.html` оказался в корне репозитория.
6. Внизу страницы нажмите **Commit changes**.

## Как включить GitHub Pages

1. В репозитории откройте **Settings**.
2. В меню слева выберите **Pages**.
3. В разделе **Build and deployment** установите **Deploy from a branch**.
4. В поле **Branch** выберите `main`, а в поле папки — `/ (root)`. Нажмите **Save**.
5. Подождите пару минут и обновите страницу **Settings → Pages**. Там появится адрес сайта вида `https://ВАШ-ЛОГИН.github.io/between-us-1330/`.
6. Откройте ссылку и отправьте её Лёне.

Если GitHub создал репозиторий с другой веткой, выберите её в поле **Branch** вместо `main`.

## Примечание о совместной игре

Сейчас имена, расстояние и история заданий сохраняются в браузере на одном устройстве. Для синхронизации прогресса Даши и Лёни между разными телефонами потребуется подключить облачную базу данных. Публикация через GitHub Pages сама по себе такую синхронизацию не добавляет.
